# Обработка GPX-треков и формирование отчёта

## Состав проекта

- `input.ini` — файл конфигурации.
- `math_d.py` — Python-скрипт обработки GPX-файлов.
- `rez.txt` — результат работы в виде команд для `go.cmd`.

## input.ini

Файл конфигурации для `math_d.py`.

```ini
[files]
in_path=e:\cards\gpx\
in_file_mask=Card_202*.gpx
out_file_full=rez.txt

[limits]
delta_time=10
;sec
camera_max_distance=90
;m
speed_limit=0
;km/hr

[camera]
lat=55.611836
lon=37.364985
;ÐÞÁðµþ« 55.495798 36.965170
```

### Описание секций

#### [files]

- `in_path` — путь к папке с GPX-файлами.
- `in_file_mask` — маска файлов для обработки.
- `out_file_full` — имя выходного файла отчёта.

#### [limits]

- `delta_time` — временной интервал в секундах.
- `camera_max_distance` — максимальное расстояние до камеры в метрах.
- `speed_limit` — ограничение скорости в км/ч (0 — не учитывать).

#### [camera]

- `lat`, `lon` — координаты камеры.

## math_d.py

### Назначение

Скрипт читает `input.ini`, анализирует GPX-файлы из указанной папки, вычисляет расстояние до камеры, скорость и формирует отчёт `rez.txt` в виде команд для `go.cmd`.

### Функции

- `haversine(lat1, lon1, lat2, lon2)` — вычисляет расстояние между двумя точками на Земле в метрах.
- `parse_ini_file(ini_path)` — читает конфигурацию из `input.ini`.
- `process_files(params)` — обрабатывает файлы и записывает отчёт.

## rez.txt

Файл содержит строки вида:

```text
call go.cmd list Card_20230624.gpx 04:52:38 20230620045228 20230620045248 105.7 58.6
```

### Формат строки

```text
call go.cmd list [имя_файла] [время] [дата_начала] [дата_конца] [скорость] [расстояние]
```

- `имя_файла` — имя GPX-файла.
- `время` — время проезда.
- `дата_начала` — дата и время начала интервала.
- `дата_конца` — дата и время конца интервала.
- `скорость` — скорость в км/ч.
- `расстояние` — расстояние до камеры в метрах.

## Цикл работы

1. Настроить `input.ini`: пути, координаты камеры, лимиты.
2. Запустить `python math_d.py`.
3. Получить `rez.txt` со строками `call go.cmd list ...`.
4. Использовать `rez.txt` с `go.cmd`.
